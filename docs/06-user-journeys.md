# 06 — User Journeys

## J1: Homeowner, mobile, searching "sliding gates gold coast"
Google → `/services/gates` → scrolls the gallery → taps the sticky **Quote** → `/contact?service=gates` (service pre-selected) → submits 5 fields → `/thank-you` (`generate_lead`). Alternative: taps **Call** (`click_phone`).

## J2: Pool owner comparing options
Home → Services tile "Pool Fencing" → reads glass vs aluminium and the FAQs → Projects filtered to Pool → back to Quote.

## J3: Builder or developer
Home → Builders & Commercial band → `/builders-commercial` (multi-res balustrades, façade screens) → Contact with service "Builder / Commercial project" → optional plan upload (phase 2) or email.

## J4: Referral visitor checking credibility
Facebook/referral → Home → Projects → project detail → About (family-run, factory, licence) → Call.

## Friction rules
- No page more than 1 tap from a quote action.
- Form errors appear inline and are announced to screen readers. Field values are kept on error.
- Phone is visible in the header on desktop and in the sticky bar on mobile.
